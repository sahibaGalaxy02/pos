# Point of Sale (POS) System

A complete, production-ready web-based Point of Sale system built with **HTML**, **Tailwind CSS**, **Vanilla JavaScript**, and **Google Sheets** as a backend via Google Apps Script.

## Features

✅ **Inventory Management** - Track products, stock levels, and pricing  
✅ **Sales Processing** - Fast and intuitive checkout experience  
✅ **Real-time Sync** - Data synchronization with Google Sheets  
✅ **Responsive Design** - Works seamlessly on desktop and mobile devices  
✅ **User-friendly Interface** - Clean UI built with Tailwind CSS  
✅ **No Backend Required** - Leverages Google Apps Script for backend operations  

## Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **Backend:** Google Apps Script
- **Database:** Google Sheets
- **Architecture:** Client-side rendering with cloud-based data storage

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sahibaGalaxy02/pos.git
   cd pos
   ```

2. Set up Google Sheets integration:
   - Create a Google Sheet for your data
   - Deploy a Google Apps Script to handle backend operations
   - Add your script deployment URL to the configuration

3. Open `index.html` in your browser or deploy to a hosting service

## Usage

1. Start by adding products to your inventory via the POS interface
2. Process sales by selecting items and quantities
3. Complete transactions with customer information
4. View sales reports and analytics in the connected Google Sheet
